# QueryPilot roadmap: gap analysis

This maps the developer needs in [research/developer-needs.md](research/developer-needs.md) against what QueryPilot ships in `main` (v0.1.1) and ranks the gaps. Last updated 2026-10-20.

Impact is how much the change helps an engineer adopting QueryPilot, or how much it lifts SQL quality. Effort is S (a day or less), M (a few days) or L (a week or more). Items marked **this PR** are the ones implemented on `feat/agent-dx`.

## Already covered elsewhere

[PR #25](https://github.com/nickklos10/QueryPilot/pull/25) fixes the validator scope (CTEs, select aliases, subqueries, UNION), applies masking through column lineage, caps non-literal LIMITs and opens SQLite read-only. On `main`, 39 of the 65 SaaSPulse correctness golds fail QueryPilot's own validator; with PR #25 all 65 pass. Everything below assumes PR #25 has landed, and nothing here touches `validation/validator.py` or `connectors/sqlite.py`.

## Build plan for this PR

1. **Connect from any URL.** `QueryPilot.connect(url)` infers the dialect, and a generic SQLAlchemy connector covers DuckDB, MySQL/MariaDB, SQL Server, Snowflake, BigQuery, Redshift, Oracle, Trino and Databricks. Introspection covers PKs, FKs, comments, views and non-default schemas, and the schema is cached. Each engine uses its native read-only mode where one exists. Dialect-aware blocked functions ship here too.
2. **Agent toolkit.** A single `QueryPilotToolkit` defines `list_tables`, `describe_table`, `search_schema`, `run_sql`/`execute_sql`, `validate_sql` and `ask_database`. It returns structured errors instead of raising and reports `truncated`. It is exposed as OpenAI (Chat and Responses), Anthropic, MCP (with `readOnlyHint`), LangChain (with `sql_db_*` aliases), LlamaIndex, OpenAI Agents SDK and Claude Agent SDK tools.
3. **Repair that converges.** Errors suggest likely names ("did you mean `customer_name`?"), list valid columns and strip ANSI codes. Database errors and empty results also go back to the model. The default is 3 attempts.
4. **Grounded schema context.** The prompt includes PKs, FKs, comments, up to 3 sample values for text columns, and user-supplied `hints` (a glossary or business rules). Above a token budget, only relevant tables are sent, plus the FK bridge tables that connect them.
5. **First five minutes.** `pip install querypilot`, then `querypilot ask "…" --db URL`, `querypilot schema --db URL`, and `querypilot demo`, which uses a bundled demo DB. `serve`/`mcp` take `--generator`/`--model`, and `querypilot mcp-config <client>` prints the client config. server.json is fixed, and the README is reordered so the first query comes first.
6. **Measure.** SaaSPulse is run before and after with the same model.
